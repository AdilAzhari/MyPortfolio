# Open Graph Image

Please add an Open Graph image with the filename `og-image.jpg` to this public directory.

## Image Requirements:
- Dimensions: 1200x630 pixels
- Format: JPG or PNG
- File size: Under 1MB
- Content: Should represent your portfolio/brand

## Recommended Content:
- Your name and title
- Professional photo or logo
- Clean, branded design
- High contrast text for readability

The image will be used when your portfolio is shared on social media platforms like LinkedIn, Twitter, and Facebook.
